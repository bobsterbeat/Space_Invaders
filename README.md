# Space Invaders Deluxe

A browser-based Space Invaders game built with HTML5 Canvas and JavaScript.

Play the game here:

https://bobsterbeat.github.io/Space_Invaders/

---

## Controls

Move Left  
• Left Arrow or **A**

Move Right  
• Right Arrow or **D**

Shoot  
• **Space Bar**

Pause / Resume  
• **P**

Restart after Game Over  
• **Enter**

---

## Gameplay

• Destroy waves of alien ships  
• Avoid enemy fire  
• Use the green shields for protection  
• Survive through multiple levels  
• Defeat the **boss ship on Level 3**

---

## Features

• Retro arcade gameplay  
• Animated explosions and particles  
• Sound effects  
• Local high-score tracking  
• Playable directly in the browser (no installation)

---

## Technology

• HTML5 Canvas  
• JavaScript
